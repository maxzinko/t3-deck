# Changelog

## 1.0.0

First public release.

- Keys: T3 Status, Thread slots, Quick Reply, Stop, Mark Done, New Thread, Open T3 Code, T3 Shortcut.
- Dials (Stream Deck +): Threads, Reply, Thread Navigator.
- Profiles for the Stream Deck +, MK.2 (15 keys) and XL: *T3 Deck Desktop* and *T3 Deck Code*.
- The deck follows the program in front (rules in the T3 Status key's settings).
- Setup checklist on the T3 Status key's settings page.
- Gets its own scoped T3 Code session from T3's command line and renews it.
